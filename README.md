# Portfolio

Personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Tech Stack

- React 19 + Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis (smooth scroll)
- i18next (multi-language support)
- Lucide React (icons)

## Features

- Apple-style hardware device frames (Safari window, iPhone, iPad Pro)
- Interactive project showcase with sticky stacking card animation
- Dark and Olive/Light theme support with smooth transitions
- Multi-language localization (EN, UK, ES, FR, PL, CS, SK, RU)
- Mobile-first responsive layout with custom full-screen navigation drawer

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
